1. LocalStorage
   LocalStorage는 웹 브라우저의 저장소 중 하나로, 클라이언트 측에서 데이터를 영구적으로 보관하는 방법

특징:

- 영구적 저장: 사용자가 명시적으로 삭제하지 않는 한 브라우저에 데이터가 영구적으로 보관
- 용량: 일반적으로 약 5MB 정도의 저장 용량
- 데이터 접근 범위: 같은 도메인에서 접근 가능하며, 도메인 및 프로토콜 단위로 데이터를 저장
- 데이터 형식: 문자열 형태로만 저장할 수 있기 때문에, JSON 형식의 데이터를 저장하려면 문자열로 변환 필요

보안:

- 데이터 노출 가능성: LocalStorage에 저장된 데이터는 클라이언트 측에 저장되기 때문에, JavaScript를 통해 접근할 수 있음
- 민감 정보 저장 제한: LocalStorage는 암호화가 기본적으로 적용되지 않으므로, 로그인 토큰이나 개인 정보 같은 민감한 데이터를 저장하기에 적합하지 않음
- 서버 전송 없음: LocalStorage의 데이터는 서버로 자동 전송되지 않으므로, 클라이언트와 서버 간의 요청에 데이터가 포함되지 않아 전송 중 가로채기 위험이 없음

주로 사용되는 상황:

- 사용자 설정 및 선호도 저장: 테마 설정, 글꼴 크기 등 사용자의 환경 설정을 저장하여 페이지를 재방문했을 때 동일한 설정을 유지
- 상태 관리: 쇼핑몰의 장바구니 정보나 게임의 진행 상황처럼, 클라이언트 측에서만 필요한 상태 데이터를 저장하는 데 사용

2. SessionStorage
   SessionStorage는 웹 브라우저의 세션 기반 저장소로, 세션이 유지되는 동안만 데이터를 저장

특징:

- 세션 단위 저장: 현재 브라우저 탭에서 세션이 유지되는 동안만 데이터가 유지, 세션이 종료되면 데이터는 자동으로 삭제
- 용량: LocalStorage와 비슷한 크기인 약 5MB
- 데이터 접근 범위: 현재 탭 내에서만 접근 가능, 같은 도메인이라도 다른 탭이나 창에서는 접근할 수 없음
- 데이터 형식: LocalStorage와 마찬가지로 문자열 형식으로만 데이터를 저장

보안:

- XSS 취약: LocalStorage와 마찬가지로 클라이언트 측에서 접근 가능해, XSS 공격에 노출될 수 있음
- 서버 전송 없음: SessionStorage 데이터 역시 서버로 자동 전송되지 않음

주로 사용되는 상황:

- 세션 정보 저장: 로그인 세션 동안만 필요한 일시적 정보 저장, 예를 들어 사용자 인증 토큰을 세션 동안만 유지
- 페이지 간 정보 공유: 같은 탭 내에서 페이지 이동이 발생할 때, 임시 데이터를 유지하기 위해 활용

3. Cookie
   Cookie는 클라이언트 측에서 서버와 데이터를 주고받기 위해 사용하는 저장소

- 만료 시간 설정 가능: 쿠키는 expires 또는 max-age 속성을 통해 만료 시간을 설정할 수 있고 만료 시간을 설정하지 않으면 세션 쿠키로 간주되어 브라우저가 닫히면 삭제
- 자동 전송: 쿠키는 특정 도메인 및 경로와 연결되며, 사용자가 설정한 웹사이트를 방문할 때마다 해당 도메인에 자동으로 쿠키가 전송
- 보안 옵션: 쿠키는 HttpOnly 옵션을 설정하여 JavaScript에서 접근할 수 없도록 할 수 있고, Secure 옵션을 사용하면 HTTPS 연결에서만 전송
- 용량: 각 쿠키의 크기는 4KB 이하로 제한되며, 각 도메인별로 최대 20개의 쿠키를 저장할 수 있음

보안:

- 자동 전송: 쿠키는 HTTP 요청마다 자동으로 서버로 전송되므로, 세션 관리와 같은 서버 측 인증에 적합
- 보안 옵션:
  - HttpOnly: 쿠키에 HttpOnly 옵션을 설정하면 JavaScript로 접근할 수 없으므로, XSS 공격 방어 가능
  - Secure: Secure 옵션을 활성화하면 HTTPS 연결에서만 쿠키가 전송됨

주로 사용되는 상황:

- 세션 관리: 로그인 세션을 유지하는 데 자주 사용
- 사용자 설정 및 맞춤형 서비스 제공: 사용자가 설정한 언어, 지역 등을 기억하여 개인화된 사용자 경험을 제공
- 분석 및 추적: 광고 및 웹사이트 분석을 위해 사용자의 행동을 추적
