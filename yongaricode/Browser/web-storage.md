# Web Storage

: **해당 도메인과 관련된 특정 데이터를** 서버가 아니라 **클라이언트 웹브라우저에 저장**할 수 있도록 제공하는 기능

### 특징

- WebS Storage의 개념은 **키/값** 쌍으로 데이터를 저장하고, **키를 기반으로 데이터를 조회**
- **영구저장소(LocalStorage)**와 **임시저장소(SessionStorage)**를 따로 두어 **데이터의 지속성을 구분**할 수 있어 응용 환경에 맞는 선택이 가능
- **사이트의 도메인 단위로 접근이 제한**
- 스토리지는 데이터가 클라이언트단에 저장만 되어있을 뿐 서버로의 전송은 이루어지지 않음
- 용량 제한이 쿠키에 비해 넉넉하고, 만료일자를 따로 정하지 않음
- 오리진 단위로 접근이 제한되는 특성 덕분에 외부에서 값을 꺼내 쓸수 없다.(CSRF)
- 스토리지는 단순한 문자열을 넘어서 객체 정보를 저장할 수 있으므로 쿠키에 비해 개발 편의성이 증가

## Local Storage vs Session Storage

: **데이터의 유지와 범위에서 차이가 있다.**

### Local Storage

: **영구 / 브라우저간 공유**

- 브라우저를 종료해도 데이터를 영구적으로 보관
- 도메인만 같으면 모든 브라우저 간에 전역적으로 데이터가 공유되는 특성

```tsx
// 저장
localStorage.setItem("key", "value");

// 조회
const value = localStorage.getItem("key");

// 삭제
localStorage.removeItem("key");
```

### Session Storage

: **비영구 / 브라우저간 공유x**

- 세션 스토리지에 저장된 데이터는 브라우저 세션이 유지되는 동안만 존재하기 때문에 브라우저가 종료되면 데이터가 삭제(비영구성).
- 도메인이 같더라도 브라우저가 다르면 각각의 세션 스토리지가 형성되어 데이터 공유가 되지 않음

```tsx
// 저장
sessionStorage.setItem("key", "value");

// 조회
const value = sessionStorage.getItem("key");

// 삭제
sessionStorage.removeItem("key");
```

# Cookie

### 목적

쿠키는 서버와 클라이언트가 지속적으로 데이터 교환을 하기 위해 만들어짐. cookie를 설정하면 이후 모든 요청은 쿠키정보를 포함하여 서버로 전송

HTTP의 stateless 때문(통신이 끝나면 상태정보를 저장하지 않는 `무상태성` 때문에 정보 저장 및 사용자를 식별하기 위해서는 매번 전송해야함 )

→ 쿠키에 쓸데없는 값이 많다면 그만큼 네트워크 트래픽이 증가

### 특징

- 4KB의 데이터 저장 제한(300개, 하나의 도메인당 20개)
- HTTP Request에 암호화 되지 않은 상태로 사용하기 때문에 보안에 취약하다.
- 쿠키는 모든 HTTP Request에 포함되어 있어 웹서비스 성능에 영향을 줄 수 있다.
- 쿠키는 만료일자를 설정하지 않으면 세션쿠키, 설정하면 지속적쿠키로 간주 됨(세션쿠키의 경우 메모리에 저장 되어 브라우저나, 탭이 닫히면 삭제, 지속적쿠키의 경우 디스크에 저장되어 만료일 전까지 영구 저장)
- 클라이언트 측에 저장되기 때문에 보안 문제 노출 가능성 높음
- 여러 상황에서 정보가 삭제될 수 있음
  - 만료 기간 경과, 브라우저 종료, 도메인 또는 경로 변경 등

```tsx
// 저장 (유효 기간 설정 가능)
document.cookie =
  "key=value; path=/; expires=" + new Date(Date.now() + 864e5).toUTCString(); // 1일 유효

// 조회
const getCookie = (name) => {
  const value = "; " + document.cookie;
  const parts = value.split("; " + name + "=");
  return parts.length === 2 ? parts.pop().split(";").shift() : null;
};
const value = getCookie("key");

// 삭제 (유효 기간을 과거로 설정)
document.cookie = "key=; path=/; expires=Thu, 01 Jan 1970 00:00:00 UTC";
```

# Web Storage vs Cookie

- **서버 전송 여부**
  - **쿠키**: 모든 웹 요청 시 서버로 전송되며 네트워크 트래픽에 영향을 미칠 수 있음.
  - **Web Storage**: 클라이언트에만 저장되고 서버로 전송되지 않아 네트워크 트래픽 비용을 줄일 수 있음.
- **저장 데이터 유형**
  - **쿠키**: 문자열 데이터만 저장 가능.
  - **Web Storage**: 문자열 외에 구조화된 객체 데이터 저장 가능(브라우저 지원 필요).
- **용량 제한**
  - **쿠키**: 개수(300개) 및 용량(4KB) 제한이 있음.
  - **Web Storage**: 용량 제한이 없어 대용량 데이터 저장에 적합.
- **데이터 보존 기간**
  - **쿠키**: 만료일자가 있으며, 만료되지 않도록 설정하려면 만료일을 멀리 지정해야 함.
  - **Web Storage**: 만료일자가 없어 한 번 저장 시 영구적으로 보존됨.
